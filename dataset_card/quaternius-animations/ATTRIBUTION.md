# quaternius-animations: attribution

**What:** 89 humanoid animation clips on one rig, from the Universal Animation Library 1
(46 clips, including walk, run, jog, sprint, crouch, death, dance and driving) and the
Universal Animation Library 2 (43 clips, including climbing, interaction and emotes). It also
includes a female mannequin model.

| File | Source |
|---|---|
| `universal-animation-library-1.glb` | Universal Animation Library [Standard], Godot GLB |
| `universal-animation-library-2.glb` | Universal Animation Library 2 [Standard], Unreal/Godot GLB |
| `mannequin-female.glb` | Universal Animation Library 2 [Standard], female mannequin |

**Created by:** [Quaternius](https://quaternius.com). Free Standard tiers, downloaded from
OpenGameArt ([UAL 1](https://opengameart.org/content/universal-animation-library),
[UAL 2](https://opengameart.org/content/universal-animation-library-2)).

**License:** CC0 1.0 (public domain). The original license files are kept as
`LICENSE-UAL1.txt` and `LICENSE-UAL2.txt`. Credit isn't required, but please consider
supporting Quaternius at https://www.patreon.com/quaternius.

**What we changed:** nothing. We only renamed the files.

**Note:** this rig is not the Rocketbox (3ds Max Biped) rig. To play these clips on
Rocketbox people, retarget them, for example with three.js `SkeletonUtils.retargetClip`.
