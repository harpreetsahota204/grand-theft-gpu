## Rules of the run

- You are working alone in the current directory. Build everything here.
- The game must open from `index.html` in this directory, served by a plain static file server. No build step is run for you; if you use one, commit its output.
- Keep working until you consider the game finished. When you do, create `DONE.md` with a short summary of what you built. Do not create `DONE.md` before then.
